`RP2350-Zero.wrl` is a simple stand-in 3D model of the Waveshare RP2350-Zero (black PCB, gold castellations, USB-C, RP2350, flash, RGB LED, buttons) sitting on the 8.5 mm female sockets. It is only used for renders.

Renders are made with `../render.kicad_jobset` (KiCad 9/10: `kicad-cli jobset run`), which uses the board's stackup colours (black mask, white silk).
